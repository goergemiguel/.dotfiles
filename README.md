## Using stow to manage dotfiles

Following this [guide](https://medium.com/@jacksmithxyz/git-symlinks-and-gnu-stow-how-to-manage-your-dotfiles-103c42cea485)

## Prerequisites

- nvim
- fish
- tmux
- wezterm
- Tmux package manager (TPM)
- stow

> PS: clone Tmux TPM to ~/.config/tmux/plugins/tpm

## Installing on new machine

1. Clone branch to Home directory
2. Inside `.dotfiles` directory, run `stow .`
